# material-design---design-system-study
Material Design 3 – Design System Study

📌 Project Overview

This project explores the fundamentals of Material Design 3, Google's design system. It showcases 10 commonly used UI components along with their purposes and basic usage guidelines.

🎨 Components Covered

1. Buttons
2. Text Fields
3. Cards
4. Navigation Bar
5. App Bar
6. Checkboxes
7. Radio Buttons
8. Switches
9. Chips
10. Dialogs

🎯 Project Objective

- Understand the fundamentals of design systems.
- Explore commonly used UI components.
- Learn component states and usage guidelines.
- Improve UI consistency and visual design skills.

🛠️ Tools Used

- Figma
- Material Design 3 Guidelines
